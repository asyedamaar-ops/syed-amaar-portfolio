PROJECTS

Explainable Cardiac Arrhythmia Detection

PYTHON · TENSORFLOW · DENSENET · ATTENTION · GRAD-CAM

Classified five AAMI heartbeat classes on MIT-BIH (87,554 training and 21,892 test beats) with a 113:1 class imbalance, using ECG-aware augmentation and class weights. Compared a CNN (98.19%, macro F1 0.910), an improved DenseNet (98.66%, 0.923) and a DenseNet with multi-scale attention (98.44%, 0.915). A patient-wise re-evaluation (DS1/DS2, 5 seeds, identical data and settings) cut macro F1 from 0.90 to 0.41 on unseen patients, so the by-beat figures are optimistic. GitHub

QSteg: Quantum-Keyed Image Steganography

PYTHON · QISKIT · AES-256-GCM · DCT/QIM · COURSE PROJECT

Generated AES-256 keys from Qiskit Hadamard circuits on the Aer simulator, encrypted payloads with AES-256-GCM and embedded the ciphertext in mid-frequency DCT coefficients using QIM with a key-ordered block sequence. Tested with PSNR, SSIM and LSB-targeted chi-square and RS steganalysis, and added a decode round-trip check after finding that saturated images corrupt the payload. GitHub

VISION

Two visual classes

The dataset configuration defines Concentric_Crack and Pothole as the two YOLOv8 detection classes.

SENSOR SIGNAL

Severe Z-axis drop

The extraction workflow uses the median Z-axis value as a baseline and filters labelled bad-road events for a substantial drop below that baseline.

IMPLEMENTATION

Python pipeline

Pandas handles sensor data processing, while OpenCV and YOLO inference support the video-processing workflow.

Scope note: the repository uses pothole/concentric-crack visual classes and sensor-based severe-drop logic as evidence for a potential sinkhole event. It should not be described as a YOLO model directly trained on a “sinkhole” class.

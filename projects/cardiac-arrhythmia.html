Test-set metrics from two training runs. The ranking changed between runs (the attention model had the best accuracy in run 2 only), while the DenseNet led on macro F1 in both, so the differences are small. The train and test files are split by beat, not by patient, so the figures are probably optimistic. I then re-ran all three models on a patient-wise split (DS1/DS2, 5 seeds, identical data and settings): macro F1 fell from 0.90 to 0.41 on unseen patients, so the by-beat figures mostly reflect patients the model had already seen.

MY CONTRIBUTION

What I actually worked on

  • Designed the MySQL schema (8 tables, 3 views, 2 SQL triggers).
  • Built the Flask backend: authentication, role-based access, booking, cancellation and an admin module.
  • Implemented per-class seat availability, automatic waitlisting and first-in-first-out waitlist promotion on cancellation.
  • Fixed a race condition that sold one seat to several simultaneous requests, using row-level locking (SELECT ... FOR UPDATE), locking reads and a unique seat index. The fix was made in a review with an AI coding assistant.
  • Added CSRF protection and 44 pytest tests, including concurrency tests that run on MySQL in GitHub Actions.
  • Seeded 2,580 daily schedules across 2 lines and 8 stations.

Quantum Steganography

Qiskit key generation · AES-256-GCM · DCT/QIM8-qubit workflow

THE PROJECT

A quantum-keyed image steganography system. An AES-256 key is generated from Qiskit Hadamard circuits, the message is encrypted with AES-256-GCM, and the ciphertext is hidden in DCT coefficients of a cover image.

MY CONTRIBUTION

What I actually worked on

  • Designed and built the whole pipeline as a course project: key generation, encryption, embedding and decoding.
  • Generated the 256-bit AES key from 8-qubit Hadamard circuits on the Qiskit Aer simulator and encrypted payloads with AES-256-GCM.
  • Embedded the ciphertext in mid-frequency DCT coefficients using QIM, with the block order keyed by the key.
  • Measured PSNR and SSIM, tested against LSB-targeted chi-square and RS steganalysis, found a decode failure on saturated images and added a round-trip check.
